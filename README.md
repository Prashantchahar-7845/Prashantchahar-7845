# `02 / THE MAIN QUEST`

<div align="center">

# ⚡ CLASS<span style="color:#67E8F9">PULSE</span>

### `AI-POWERED CLASSROOM INTELLIGENCE`

</div>

> **A real-time Computer Vision system designed to understand what is happening inside a classroom.**

### The idea

ClassPulse combines multiple AI systems into one pipeline capable of monitoring a classroom of **70+ students**.

```text
        ┌───────────────┐
        │    CAMERAS    │
        └───────┬───────┘
                │
                ▼
      ┌───────────────────┐
      │   COMPUTER VISION │
      └─────────┬─────────┘
                │
     ┌──────────┼──────────┐
     │          │          │
     ▼          ▼          ▼
   FACE       HAND       PHONE
   AI         AI          AI
     │          │          │
     └──────────┼──────────┘
                ▼
       ┌─────────────────┐
       │   AI PIPELINE   │
       └────────┬────────┘
                │
       ┌────────┴────────┐
       ▼                 ▼
  ENGAGEMENT          ALERTS
       │                 │
       └────────┬────────┘
                ▼
        TEACHER DASHBOARD
```

### `WHAT IT CAN DO`

| Vision System              | Purpose                     |
| -------------------------- | --------------------------- |
| 👤 **Face Recognition**    | Automated attendance        |
| ✋ **Hand-Raise Detection** | Detect raised hands         |
| 📱 **Phone Detection**     | Identify phone usage        |
| 📊 **Engagement Analysis** | Understand student activity |
| 🔔 **Alert Engine**        | Notify the teacher          |
| 🖥️ **Dashboard**          | Real-time classroom view    |

### `STACK`

`Python` `OpenCV` `MediaPipe` `YOLOv8` `FastAPI` `PostgreSQL` `React.js` `Raspberry Pi` `ESP32`
